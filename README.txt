Shin Koihime † Musou -Kakumei- Souten no Haou English Patch
Version 1.2.5

Full English patch for the main story, character routes, battles, menus,
and extras. Version 1.2.5 fixes long pauses when advancing past merged dialogue.

REQUIREMENTS

Use your own installed copy of the original Japanese Windows base game.
Check that the game launches with your usual Japanese locale setup.
This release targets the base game.

INSTALLATION

1. Close the game and its launcher.
2. Open the game folder containing bootmenu.exe and souten.exe. Back up
   any existing copies of the files listed below. Keep a copy of
   your saves as well. The launcher has an Open Save Folder button.
3. Extract the patch into the game folder. Preserve the config and
   html folders and accept file replacements.
4. Open bootmenu.exe and choose Launch Game.

    update99.int
    movie.int
    efktex.int
    bootmenu.exe
    souten.exe
    cs2conf.dll
    config/startup.xml
    boot.hg3
    banner.bmp
    html/ (19 English HTML pages)

EXISTING SAVES

The patch uses the original save folder. Saved previews and backlog
entries can retain older text. A new game gives you a clean English
backlog. The separate launcher title bar uses the original Japanese
product name. The game window uses the English title.

RESTORATION

Close the game and its launcher. Restore the files you backed up and
remove any patch files that were absent before installation.
